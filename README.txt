# Lærðu Íslensku
Aplicativo gratuito de aprendizagem de islandês, português -> islandês.

## O que já está pronto
- 10 aulas iniciais
- vocabulário e frases práticas
- pronúncia usando a voz do dispositivo (is-IS)
- quizzes
- pontos e progresso
- funcionamento offline depois do primeiro carregamento
- interface adaptada a telemóvel

## Como colocar online gratuitamente
1. Crie uma conta no GitHub.
2. Crie um repositório, por exemplo `laerdu-islaensku`.
3. Envie todos os arquivos desta pasta.
4. Ative GitHub Pages nas configurações do repositório.
5. Abra o endereço gerado no telemóvel e escolha "Adicionar à tela inicial".

## Observação
A voz islandesa depende das vozes instaladas/disponíveis no navegador ou no sistema do telemóvel.
